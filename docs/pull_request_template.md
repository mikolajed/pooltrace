## Change

Describe the problem and resulting behavior. Link the approved task and relevant ADR; state the
bounded scope of the user's authorization.

## Validation

List the checks actually run and their results. Link hosted runs or selected sanitized evidence
when useful, and identify the tested candidate. Distinguish local checks from hosted checks.

## Remaining limitations

State failures, skipped checks, external dependencies and material risks, or say none identified.
Keep the PR draft while required checks are failing, missing or stale. Human review and merge
remain separate from successful CI.
